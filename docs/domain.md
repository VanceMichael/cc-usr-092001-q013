# 领域约定

月饼跨境合规批次台围绕出口产品、标签版本与物流批次保存可核对的业务记录。外部主体使用不含真实身份信息的稳定引用编号，时间采用带偏移量的 ISO 8601 字符串，材料只保存受控引用和 `sha256` 摘要。

交换事件包含 `event_id`、`subject_ref`、`occurred_at`、`source_sequence` 和 `payload_digest`。来源序号只在同一来源内递增，接收方必须保留原始发生时间，不得用到达时间覆盖。示例内容仅用于说明字段形状，不代表真实人员、机构或业务结论。

## 核心对象

- **配方版本**（recipe_versions）：某产品配料、过敏原、营养声明的不可变快照。
- **标签版式**（label_layouts）：某一语言、绑定某一配方版本的包装版面，含实际标注的过敏原与 `sha256` 图稿摘要。
- **目的国规则**（market_rules）：按 `effective_from`/`effective_to` 衔接的版本链，规定可接受语言、禁用配料、必须标注的过敏原与包装规范。
- **批次与货位**（batches / lots / lot_links）：批次下生产出货位；拆分消耗父货位生成子货位，合并跨批次生成无单一归属的新货位，血缘全部留痕。
- **箱**（cases）：装箱扫描时建立的最小追踪单位，记录目的地、经销商引用、所用标签版式与核准规则版本。
- **柜次**（shipments）：loading → pending_customs → departed → arrived。

## 不变量

1. **数量守恒**：拆分要求子货位之和等于父货位；合并要求同一配方版本；装箱扣减货位剩余；生产累计不得超过计划量。所有数量移动在事务内完成，任何路径都不创造数量。`GET /v1/batches/:id` 返回守恒核对数。
2. **幂等**：箱号、回执号、`event_id` 重复提交返回首次结果（响应头 `idempotent-replay: true`），重复扫描与经销商重传不增加货量。回执经销商必须与装箱登记一致，累计回执不得超过箱内数量。
3. **目的地级阻断**：装箱扫描或规则复评不合格时，只在 （市场， 配方， 批次） 维度建立阻断；同批货物发往其他目的地不受影响。阻断期间禁止装柜，须登记原因后显式解除。
4. **规则更新分别处理**：新规则版本登记时自动复评——未生产批次触及新禁令的标记 `review` 并禁止继续生产；待报关/未离港的箱逐箱复评，不合格转 `held` 并阻断目的地；已离港/已到港的柜保留离港时的核准版本，仅登记告知（rule_notices），不予追溯。
5. **可解释**：`GET /v1/cases/:ref/explanation` 回答一箱产品为何获准出口——依据哪版规则、哪种语言标签、哪次检查、经哪个柜次、数量如何流转。
6. **召回精确**：召回按批次（沿拆分/合并血缘）或配方版本圈定范围，按市场汇总受影响箱数与剩余包装（未售罄），已售罄的箱保持原状只列入清单。

## 隐私

系统不存储经销商合同价格等商务条款，经销商只以稳定引用编号出现。复购汇总（`GET /v1/reports/repurchase`）只按产品/市场输出聚合量与复购经销商计数，不输出任何经销商级明细。
